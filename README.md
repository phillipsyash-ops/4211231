# Loyal — кошелёк монет ‑x

Игровой кошелёк для своего круга: USDT‑x, BTC‑x, ETH‑x, SOL‑x, BNB‑x, TON‑x, TRX‑x, XRP‑x.
Монеты появляются только через админку — напрямую или по заявке пользователя. Курсы реальные
(Binance, запасной источник CoinGecko), с графиками. Есть расширение для браузера.

## Установка на хостинг (cPanel / Namecheap и подобные)

1. **SSL.** Убедитесь, что домен открывается по `https://` (cPanel → SSL/TLS Status → AutoSSL).
2. **PHP.** cPanel → Select PHP Version → версия 8.1 или новее, включены `pdo_mysql`, `mbstring`, `curl`, `zip`.
3. **База.** cPanel → MySQL Databases:
   - создайте базу (например `loyal`, полное имя будет `аккаунт_loyal`);
   - создайте пользователя с надёжным паролем;
   - добавьте пользователя к базе с правами **ALL PRIVILEGES**.
4. **Файлы.** Загрузите всё содержимое этой папки в папку домена (обычно `public_html`)
   или в подпапку. Скрытые файлы `.htaccess` тоже нужны.
5. **Установщик.** Откройте `https://ваш-домен/install.php`, заполните базу и логин/пароль админа.
   Установщик создаст таблицы и секретные ключи, покажет **ссылку на админку** (сохраните её!)
   и удалит сам себя.
6. **https‑перенаправление.** В `.htaccess` уберите `#` у трёх строк в конце.

Повторно открыть установщик нельзя — если нужно переустановить, удалите `config.local.php`
и загрузите `install.php` снова (данные в базе сохранятся).

## Админка

`https://ваш-домен/admin/?k=КЛЮЧ` — без ключа отвечает «404». Ключ — `ADMIN_URL_KEY`
в `config.local.php`. Там: заявки на пополнение/вывод, начисление и списание монет,
пользователи и блокировка, все транзакции.

## Что нового

- **Промо-видео на главной** — загрузите ролик в `assets/video/promo.mp4` (обложка — `assets/video/promo.jpg`,
  необязательно). На главной сам появится блок «See it in action» с плеером и кнопка «▶ Watch video» в первом экране.
  Вместо файла можно указать ссылку YouTube в `PROMO_YOUTUBE` в `config.php`. Нет файла и ссылки — блока нет.

- **Убраны «Пополнить» и «Вывести»** — в кошельке остались «Отправить», «Получить» и «Обмен». Монеты по‑прежнему
  выдаются через админку («Начисление / списание»). Старые заявки, если были, видны во вкладке «Заявки».
- **Двухфакторная защита (2FA)** — Settings → Security → Set up. Код из Google Authenticator / Microsoft Authenticator /
  Authy при каждом входе (сайт и расширение) и при просмотре сид‑фразы. Предлагается сразу после создания
  кошелька (можно пропустить). Если пользователь потерял телефон — в админке «Пользователи» кнопка «Сбросить 2FA».
- **Уведомления о цене** — вкладка Alerts: «BTC‑x выше $110 000», «SOL‑x ниже $160». Сработавшее уведомление
  появляется вверху кабинета, в расширении и всплывающим уведомлением браузера. Цены проверяются при каждом
  обновлении курса. Чтобы уведомления срабатывали, даже когда на сайте никого нет, добавьте в cPanel → Cron Jobs
  задачу раз в минуту: `php /home/girohzut/loyal-true.com/cron.php`.
- **Заметки к пользователю** — админка → «Пользователи и кошельки» → колонка «Заметки»: комментарии с датой,
  видны только администратору. Поиск находит пользователя по почте, ID, адресу кошелька или тексту заметки.

- **Новости** — вкладка News в кабинете: свежие новости из открытых RSS-лент CoinDesk, Cointelegraph, Decrypt
  и Bitcoin Magazine. Заголовок, картинка, короткий анонс, метки монет, фильтр по монете и поиск;
  по клику открывается оригинал статьи. Обновляются раз в 15 минут (`NEWS_TTL`), список лент — `$NEWS_FEEDS`
  в `config.php`. Если ленты недоступны — показывается последняя сохранённая подборка.
- **Сид-фраза в настройках** — Settings → Security → «Show recovery phrase» после ввода пароля.
  Фраза хранится зашифрованной паролем пользователя (AES‑256‑GCM): без пароля её не прочитать
  ни администратору, ни тому, у кого есть база. При смене пароля перешифровывается. У старых
  аккаунтов появится после первого входа по сид-фразе (сайт или расширение).

- **Язык сайта — английский** (весь сайт, письма-уведомления расширения, само расширение). Админка и установщик — на русском.
- **Монеты из админки** — вкладка «Монеты»: добавить новую (тикер, название, пара Binance и/или id CoinGecko,
  цвет и знак значка, точность, начало адресов), кнопка «Проверить курс», выключить/включить.
  Новая монета сразу появляется у всех кошельков с адресами; график подключается по той же паре.
  Выключенная монета скрыта у пользователей, балансы сохраняются. Список из `config.php` используется
  только при первом запуске — дальше монеты живут в базе.
- **Объявления** — вкладка «Объявления» в админке: заголовок, текст, тип (информация / хорошая новость / важно).
  Показываются вверху кабинета и в расширении, пользователь может скрыть крестиком.
- **Новое лого** — монета Loyal; на главной она живая 3D‑модель (Three.js), при прокрутке уходит вдаль к краю экрана.

## Как устроено

- **Сид‑фраза** — 12 слов BIP‑39. Для входа на сервере её отпечаток (HMAC с `SEED_PEPPER`), для просмотра — копия, зашифрованная паролем пользователя.
  `SEED_PEPPER` менять нельзя — иначе никто не войдёт.
- **Кошельки** — до `MAX_WALLETS` на пользователя, у каждой монеты свой случайный адрес.
- **Суммы** хранятся целыми числами (1e‑8); переводы атомарные, в минус уйти нельзя.
- **Подтверждение паролем** — перевод и заявка на вывод требуют пароль (на сайте и в расширении);
  5 ошибок подряд — пауза.
- **Обмен** — по курсу Binance в момент обмена, без комиссии; если курс сдвинулся больше чем на 1%
  с момента, когда пользователь его увидел, обмен останавливается.
- **Обновление базы** — после заливки новых файлов недостающие таблицы и колонки создаются сами
  при первом открытии сайта (отметка — файл `data/schema_v`).
- **Пополнить / Вывести** — заявки администратору. При выводе монеты замораживаются,
  при отклонении или отмене — возвращаются.
- **Расширение** — кнопка в кабинете скачивает архив, в который сайт вписал свой адрес.
  Когда опубликуете расширение в Chrome Web Store, впишите ссылку в `EXT_CHROME_URL`
  в `config.php` — кнопка начнёт вести в магазин.
- **Название** меняется в `config.php` (`SITE_NAME`) — на сайте и в скачиваемом расширении.
